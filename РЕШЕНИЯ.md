# Решения — сайт «ИИ-боты для бизнеса»

## 2026-11-06

- Сайт нужен для доверия: чтобы видели, что это серьёзно. Клиенты по-прежнему идут в основном из рилс в директ, сайт — подтверждение.
- Стек как у сайта Сергея (C:\my-git\kravchenko-s): Next.js 16 + next-intl + SCSS-модули. Выбран ради SEO: страницы собираются заранее в готовый HTML, поисковик видит весь текст.
- Цвета и тексты — из первого прототипа (Адриатика + светлый камень). Шрифты: Unbounded для заголовков, Golos Text для текста.
- Четыре языка: русский (/ru, основной), английский (/en), украинский (/uk), черногорский латиницей (/me, код sr-ME). Первый заход без языка в адресе — открывается язык браузера, если его нет среди четырёх — русский.
- Кодовое слово в директ по языкам: ru и uk — «РАЗБОР», en — «AUDIT», me — «ANALIZA». Эти слова надо добавить в автоответы Meta Business Suite.
- Черногорский перевод сделан без носителя языка — перед запуском показать местному человеку.
- Без выдуманных отзывов и кейсов. Показываем только реальный проект Good-5. Отзывы — после первых клиентов.
- SEO: заголовок и описание на каждом языке, ссылки между языковыми версиями (hreflang), каноническая ссылка, sitemap.xml, robots.txt, разметка Schema.org (ProfessionalService и FAQPage).

## Где что править

- Все тексты и цены: src/locales/ru.json, en.json, uk.json, sr-ME.json.
- Ники Instagram и Telegram, фото, адрес сайта: src/constants/site.ts. Пустой ник — кнопка не показывается.
- Цвета: src/styles/globals.scss (вверху файла).
- Адрес сайта на проде — переменная SITE_URL в Vercel.
