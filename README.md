# ИИ-боты для бизнеса

Сайт-визитка, где я рассказываю, какие ИИ-боты делаю для бизнеса, показываю свои проекты и цены.

Боты отвечают клиентам в Telegram, WhatsApp, Instagram, Messenger и на сайте, записывают и собирают заявки, а сложные вопросы передают человеку.

## Что на сайте

- Живой пример переписки клиента с ботом
- Какие бывают боты и что они умеют — на примерах из обычного бизнеса
- Мои проекты: движок ИИ-ботов, новостной бот Good-5, сервис мониторинга Dumza, торговый бот
- Цены, порядок работы и ответы на частые вопросы
- Четыре языка: русский, английский, украинский и черногорский

## Запуск

```bash
npm install
npm run dev
```

Перед запуском скопируйте `.env.example` в `.env.local` и заполните:

- `INSTAGRAM_URL`, `TELEGRAM_URL` — куда ведут кнопки «Написать»
- `SITE_URL` — адрес сайта
- `ANALYTICS_ENABLED` — включает статистику Vercel на продакшене
